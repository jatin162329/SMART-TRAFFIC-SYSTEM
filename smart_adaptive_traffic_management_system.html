Priority Formula
Priority = w₁·(queue/max_q) + w₂·(wait/max_w) + w₃·(arrival/max_a) + w₄·(growth) − w₅·(fairness_penalty)

w₁=0.35 Queue factor   w₂=0.30 Wait factor
w₃=0.20 Arrival factor   w₄=0.10 Growth factor
w₅=0.05 Fairness penalty

Green Time = MIN_GREEN + (priority × (MAX_GREEN − MIN_GREEN))

OS Concepts Used in This Prototype
ProcessesThreadsMultithreading Mutex/SemaphoresIPC (shared memory) Priority SchedulingStarvation Prevention Critical SectionReal-time Processing AgingEvent-drivenResource Sharing
Sensor threads: 4 independent intervals simulate pthreads, each updating road state.
Controller thread: Runs priority scheduler, selects active road, calculates green time.
Signal controller: Guards signal state with mutex — only one road can be GREEN. Enforces GREEN→YELLOW→RED transitions.
Logger thread: Async log writes simulate a dedicated logging process.
IPC: Roads share traffic state via shared memory object (JS state), mutex-protected.
Starvation prevention: Aging mechanism boosts priority of waiting roads after MAX_WAIT_CYCLES cycles.
